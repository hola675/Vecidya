# Plans — Vecidya

Directorio de planes de trabajo **futuros**. No describe funciones implementadas ni autoriza despliegues.

## Aprende

- [Plan maestro de Vecidya Aprende V1](aprende/PLAN-V1.md): decisiones aprobadas, evidencia del repositorio, arquitectura propuesta, contratos, seguridad, migraciones futuras, fases secuenciales, pruebas focalizadas y criterios de aceptación.

## Reglas de uso

1. Antes de ejecutar cualquier fase, leer `AGENTS.md`, `vecidya-platform/docs/GOVERNANCE.md`, `STATUS.md`, `PROJECT_STATE.md`, `ROADMAP.md` y el plan.
2. El plan no reemplaza la documentación canónica. Cada implementación reconcilia los documentos propietarios de sus cambios.
3. Una fase = una rama/worktree propia, diff acotado, pruebas focalizadas y PR; merge y deploy requieren autorizaciones separadas.
4. El estado de implementación solo puede declararse con evidencia de código, pruebas y, para producción, HTTP fechado.

**Estado:** planificación, sin cambios de aplicación, D1, Workers ni producción.
